# 脱敏细则

主流程见 `SKILL.md`。本文件只在边界情况不确定时读取。

## 替换，不概括

脱敏是删除或替换身份信息，不是摘要。

- 保留原句的条件和限定。`It is not due to a stability concern` 不能改成"稳定性没有问题"。
- 保留原文的不确定程度。`can be extended` 不改成"将会延长"。
- 保留原文语病和拼写，必要时加方括号。不重写整句。
- 多语言段落仅在核实内容等价时去重；翻译存在差异时保留独有事实与限定。

## 邮件头

删除：

```text
From / To / Cc / Bcc / 보낸 사람 / 받는 사람 / 참조 / 发件人 / 收件人 / 抄送
Subject 中的公司代号、人名
签名档、电话、传真、地址、网址、职位
分隔线包裹的公司信息块
```

可保留并改写：

```text
Date → 只留日期时间。时区本身不增加信息时不保留。
Subject → 去掉代号后的事项，如"询价""报价""复检期"
```

依据明确的回复关系排序；最内层常是最早一封，但转发、拼接和多个分支可能例外，不能仅凭嵌套深度推断。无回复关系时才比较时间戳；冲突或缺失则注明不确定。确认内容重复后再去重。

## 角色标签

| 场景 | 标签 | 用法 |
| --- | --- | --- |
| 双方或多方机构 | A / B / C…… | 按首次出现顺序固定编号，不随收发方向改变。 |
| 同一机构内人员 | A1 / A2 / B1…… | 机构与人员分层，方向如 `A1 → B1、C1`。 |
| 机构关系不明 | U1 / U2…… | 保留独立身份，不猜测所属机构。 |
| 文章中的企业 | 甲公司 / 乙公司 | 同一实体全文只用一个标签。 |
| 不需要区分时 | 该公司 / 终端客户 / 检测机构 | 用功能，不用"某知名药企"这类仍可缩小范围的说法。 |

第三方只在与话题有关时保留，并改成功能称呼。与话题无关的抄送人直接删除。

## 保留与删除

| 信息 | 默认 | 原因 |
| --- | --- | --- |
| 产品名、物料名 | 保留 | 通常是话题本身 |
| 批号、批准文号、注册证号、PO/订单号、合同号、统一社会信用代码 | 替换；确需原值时先询问 | 精确编号可关联批次、交易、产品注册或主体；稳定标签保留同一性关系 |
| CAS 号 | 替换；确需原值时先询问 | 识别物质，不一定识别企业，但能缩小产品范围并增加组合风险 |
| 金额、数量、贸易术语 | 保留 | 属于沟通内容 |
| 城市、机场、港口 | 保留 | 物流事实；具体街道删除 |
| 国家法定假日名称 | 可保留 | "国庆后"通常不识别个人 |
| 内部项目代号 | 删除 | 可关联到企业 |
| 域名、网址路径和查询参数中的标识 | 删除或替换 | 可直接识别主体、账号或交易 |
| 通用法规编号、标准号 | 保留 | 不包括具体企业/产品的批准文号和注册证号 |

产品名、地名、日期和金额均为有条件保留项：其中的品牌和主体名称须替换，明显间接标识须处理，其他组合风险在文末说明。不得用“默认保留”绕过风险复核。

## 变体与间接标识

- 例如原文能确认“王明”“王总”“Wang Ming”是同一人员时，全部使用 A1；不同语言名称的同一性必须由上下文支持，不单凭译名猜测。
- “李工”、微信号、邮箱本地部分也要纳入实体清单。原文邮箱已删除，不代表正文中的账号片段已删除。
- “该园区唯一的 GMP 供应商”可处理为“供应商A `[限定信息已隐去]`”；该限定若是论证前提，先询问如何取舍，不静默改变论据。
- 精确日期＋小众产品＋金额可能指向具体交易。脚本无法裁决此类风险，必须逐段语义检查。

## 扫描脚本边界

- `scripts/verify_redaction.py` 仅用 Python 3 标准库，读取 UTF-8 纯文本。PDF、Office、图片等须先提取文本；最终文件的属性、批注和隐藏内容仍需另行检查。
- 别名按 NFKC＋casefold 后的字面子串查漏；不会自动生成拼音、翻译或消除插入符号，需在私有清单里枚举已识别变体。
- 输出行列号从 1 开始，基于规范化后的文本，可能不同于原文列号。默认不输出命中原文，也不修改输入。
- 大写词、日期、金额、A1 等中性编号可能触发候选；CJK 启发式覆盖不完整。返回 0 不等于脱敏通过；返回 1 不等于全部命中都应删除。逐项裁决后仍必须进行原文对照和语义复核。
- 回归测试：在技能目录运行 `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts -p 'test_*.py'`。

## 风险说明

交付时写明：

- 已删除的类别。
- 仍保留、可能与公开信息对照后指向具体交易的项。
- 未做的事：未做实体链接核查，未保证不可重识别。

不附真名到标签的对照表，除非用户明确要求。对照表另存，不放进脱敏正文。
